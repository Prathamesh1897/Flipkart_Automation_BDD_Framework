This project is a test automation framework developed to automate key functionalities of the Flipkart web application using Selenium WebDriver with Java. The framework follows industry best practices such as Page Object Model (POM) to ensure scalability, maintainability, and readability.


Tech Stack :

Programming Language: Java

Automation Tool: Selenium WebDriver

Test Framework: TestNG, Cucumber BDD

Build Tool: Maven

Design Pattern: Page Object Model (POM)

Reporting: Extent Reports

Version Control: Git
